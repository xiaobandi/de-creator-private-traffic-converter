### 步骤 2：人设文案

**做**：先用人设语气库固化画像卡，再据此写出朋友圈候选文案与社群话术。

#### 2.1 `persona-tone-lib`：人设语气画像卡

**输入来源**：`07` 一、主理人人设 + 语气样本（正/反）。

**产出：人设语气画像卡**

```
## 身份
手作香氛主理人「林晓」，29 岁，前广告公司文案，一个人做香薰蜡烛。

## 语气（5 个形容词）
温和、理性、具体、克制、不着急（慢）

## 用词偏好
- 口头禅：「说实话」「这么说吧」
- 多用场景与细节，少用形容词
- 讲事实与数字（成分、时长、克重），不喊口号

## 禁用表达
- 「家人们」
- 「绝绝子」
- 「闭眼入」（及「冲鸭」「全网最低价」等）
- 装可怜卖惨
- 贬低同行

## 示例句（正 / 反）
正：「说实话，这支蜡烛的成本我算过，大头在香精。不是我不想便宜，是便宜的香精闻起来就是不一样。」
反（禁用）：「家人们冲鸭！！这款神仙蜡烛绝绝子，闭眼入！！！」
```

**依据与结论**：全部字段来自 `07` 一；「5 个形容词」为 SKILL 输出契约要求的数量，形容词本身取自 `07`「温和、理性、具体」+「人设关键词：慢」等原文表述。
