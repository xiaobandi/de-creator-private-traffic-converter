# 03 · 场景与价值

## 谁在用

知识付费/带货类创作者（专栏转化率 5-8% 的存量群体，据 R2 调研）

## 三个典型场景

### 场景 A：引流钩子内容生成
- **触发**：人工（按活动）
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：定位目标人群→设计资料包/清单/测评钩子→合规校验
- **收益**：钩子设计外包市场价数百元/次，自产即省

### 场景 B：欢迎语与 7 天培育 SOP
- **触发**：事件（新粉加入）
- **之后**：新粉分层→7 天触达剧本→节点话术
- **收益**：替代人工逐一维护，月省约 15h；转化率每 +1pct 对知识付费创作者即数百元月增收

### 场景 C：私域内容日历
- **触发**：定时（每周）
- **之后**：朋友圈+社群内容排期→人设文案→发送提醒
- **收益**：私域内容 0.5h/天→10min，月省约 10h≈¥300

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 知识付费市场约 2808.8 亿元（据 R2 调研，艾媒咨询）；转化率 +1pct 对月收入即数百元增量，ROI 以"增收"计远超创作类 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
